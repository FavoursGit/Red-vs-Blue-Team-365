# Red vs Blue Team — Cybersecurity Labs

I'm a Digital Forensics and Cyber Security student at TU Dublin. This repository documents my practical work in offensive security, digital forensics and threat detection.

I use these exercises to understand how vulnerabilities are exploited, how attacks appear in evidence, and how security controls can be improved.

## How I document my work

Each write-up covers the objective, the tools and approach I used, relevant evidence, my findings and what I learned. I'll add code and screenshots where they help explain the result.

All offensive work takes place in authorised labs or systems I have permission to test.
