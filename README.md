# 🛡️ Red vs Blue Team: 365 Cybersecurity Challenges

**An ongoing, hands-on cybersecurity learning portfolio by Favour Godson.**

I'm a Digital Forensics & Cyber Security student at **TU Dublin**, interested in security operations, incident response and ethical hacking. Here I document what I learn about attacks, investigations and defensive engineering.

> 🚀 **Status:** Just getting started · **0 / 365 challenges completed** · Began October 2026  
> This is a long-term learning goal—not a claim that I've completed daily challenges.

## 🎯 Goals
- 🔴 **Red Team:** Learn how weaknesses can be identified and exploited in authorised labs.
- 🔵 **Blue Team:** Investigate suspicious activity with logs, packet captures and forensic artefacts.
- 🟣 **Purple Team:** Connect controlled attack techniques to detections and mitigations.
- 🐍 **Tool building:** Write, test and explain small Python security tools.

## 🧪 Documentation standard
Each completed challenge will explain its **objective, authorised environment, methodology, evidence, findings, defensive takeaways, limitations and lessons learned**. Screenshots, sample data and scripts will be sanitised before publication.

## 🔐 Ethics & responsible disclosure
All offensive activity is limited to intentionally vulnerable training systems, isolated labs or systems I own or am explicitly authorised to assess. I will not publish credentials, sensitive information, restricted challenge flags/solutions or unapproved target data. The rules of each training platform take precedence.
